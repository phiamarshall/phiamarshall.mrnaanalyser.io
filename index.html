    ODE-based mechanistic analysis. d2eGFP: full 3-state ODE. secNLuc: rate model derived from the same ODE with λ_fluor = 0.
    Model Configuration
    λ_RNA fixed from qPCR per replicate. k_mat and λ_fluor from literature. k_trans fitted per replicate by MAE.
    ODE
    secNLuc rate model: Values = protein secreted per 2h collection window at time t. Signal starts at 0, rises to a peak, then falls — described by the inactive-protein compartment of the ODE (λ_fluor = 0): signal(t) = k_trans × k_mat / (k_mat − λ_RNA) × (e−λ_RNA·t − e−k_mat·t)
    t_half_mat controls peak timing. Peak occurs at t_peak = ln(k_mat/λ_RNA) / (k_mat − λ_RNA). Adjust t_half_mat so the model peak matches the observed peak. λ_fluor is not used for NLuc.
    Fixed Protein Kinetic Parameters
    d2eGFP ≈ 2 h | EGFP ≈ 26 h | not used for NLuc
    GFP chromophore maturation ≈ 2–3 h
    f Model Equations
    ODE — Mauger 2019 / Spiewla 2026
    d[mRNA]/dt = -λ_RNA × [mRNA]
    d[inactive]/dt = k_trans × [mRNA] - k_mat × [inactive]
    d[fluor]/dt = k_mat × [inactive] - λ_fluor × [fluor] ← GFP only
    signal_NLuc(t) = k_mat × [inactive](t) ← NLuc (λ_fluor=0)
    λ_RNA — fixed from qPCR per replicate
    k_trans — sole fitted parameter (MAE minimisation)
    k_mat = ln(2) / t_half_mat | λ_fluor = ln(2) / t_half_fluor (GFP only)

    Analysis Wiki
    Methodological reference suitable for thesis defence.
    OverviewPreprocessing qPCRGFP NLucIntegrated Mechanistic ModelStatisticsLimitations

    1. Overview

    Three orthogonal assays: qPCR (direct mRNA), GFP Incucyte (continuous protein), NLuc Clariostar (discrete protein). The Mechanistic Model disentangles mRNA stability from translation efficiency.

    2. Preprocessing

    qPCR: pre-calculated RQ values, RQ(t0)=1.0 per replicate. No re-normalisation. Technical replicates averaged before fitting.

    3. qPCR - mRNA Stability

    RQ(t) = exp(-k_m*(t-t0))   t_half = ln(2)/k_m

    First-order decay. k_m fitted per biological replicate. Apparent half-life from t0 only.

    4. GFP Incucyte

    AUC by trapezoidal rule. d2EGFP t_half ~2 h. GFP signal convolves stability, translation, and turnover. Use the Mechanistic Model for decomposition.

    5. NLuc Clariostar

    Discrete-timepoint trapezoidal AUC. For mechanistic analysis, values are interpreted as secretion rates per 2h collection window.

    6. Integrated Analysis

    Parameters normalised to reference construct. Concordant increases in relative t_half and AUC support stability-driven enhancement.

    7. Mechanistic Model

    d2eGFP — 3-state ODE (Mauger 2019 / Spiewla 2026):

    d[mRNA]/dt = -λ_RNA*mRNA | d[inactive]/dt = k_trans*mRNA - k_mat*inactive | d[fluor]/dt = k_mat*inactive - λ_fluor*fluor

    λ_RNA fixed per replicate from qPCR. k_mat and λ_fluor fixed from literature. k_trans fitted by MAE minimisation.

    secNLuc — rate model (λ_fluor = 0): Values = protein secreted per 2h window = secretion rate ∝ k_mat × [inactive](t). Since secreted NLuc is stable (λ_fluor = 0), the signal is:

    signal(t) = k_trans × k_mat/(k_mat − λ_RNA) × (exp(−λ_RNA·t) − exp(−k_mat·t))

    This naturally starts at 0, rises to a peak at t_peak = ln(k_mat/λ_RNA)/(k_mat − λ_RNA), then falls. t_half_mat controls the peak timing — adjust it to match the observed peak.

    AICc comparison: Model 1 (shared k_trans) vs Model 2 (per-construct k_trans). ΔAIC > 2 supports construct-specific translation.

    8. Statistics

    Fits per biological replicate. With n < 3, descriptive statistics only.

    9. Limitations

    • First-order decay assumes negligible de novo transcription
    • No correction for cell number, viability, or transfection efficiency
    • k_trans absorbs [mRNA](0); transfection efficiency differences not corrected
    • For NLuc: t_half_mat must be tuned manually to match peak timing
